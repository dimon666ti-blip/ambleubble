# I CAN — поверніть контроль над своїм життям

Маленькі дії. Великі зміни.

Додаткову інформацію та початок роботи дивіться на опублікованому сайті:
**http://localhost:5173/ambleubble/**

---

## Про застосунок

**I CAN** — це український додаток для підтримки емоційного стану, який допомагає подолати відчуття безсильства та вивченої безпорадності. Користувач описує свою ситуацію, обирає емоційний стан та рівень складності, а отримує три прості, реалістичні кроки, які можна зробити вже сьогодні.

Застосунок працює у браузері, дані зберігаються локально, а ключ API OpenRouter (якщо надано) дозволяє отримати персональну пораду від штучного інтелекту.

---

## Головні функції

- **Генерація плану кроків** — три прості дії (1–10 хв кожен) для подолання складної ситуації
- **Коло контролю** — розділ на те, що можна控олювати, а що ні
- **Відстеження настрою** — оцінка стану до і після кроків (1–10 балів)
- **Графік динаміки настрою** — візуалізація покращення з часу
- **Історія pequenas перемог** — збереження виконаних кроків
- **Архів сесій** — перегляд і видалення раніше створених планів
- **Таймери кроків** — відлік часу для кожного кроку з збереженням після перезавантаження
- **Диктування ситуації** — введення тексту через mikrofon (Speech Recognition)
- **Темна / світла / системна тема** — зміна оформлення додатку
- **Експорт / імпорт даних** — збереження сесій у JSON та відновлення з файлу
- **П落叶 анімація** — падаючі листя осені на вступному екрані
- **Мовне оформлення** — українська мова

## Інструкція локального запуску

Потрібно встановити [Node.js](https://nodejs.org/) (рекомендовано v20+).

1. Скопіюйте репозиторій:
   ```bash
   git clone https://github.com/ambleubble/ambleubble.git
   cd amleubble
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
   Відкрийте http://localhost:5173/ambleubble/ у браузері.

4. Зберіть проєкт для продакшену:
   ```bash
   npm run build
   ```
   Готові файли будуть у папці `dist`.

### Інші корисні команди

| Команда | Опис |
|---------|------|
| `npm run dev` | Запуск сервера розробки |
| `npm run build` | Збірка для продакшену |
| `npm run preview` | Попередній перегляд збірки |
| `npm run test` | Запуск юніт-тестів (Vitest) |
| `npm run typecheck` | Перевірка типів TypeScript |
| `npm run lint` |Перевірка коду ESLint |
| `npm run test:e2e` | Запуск E2E-тестів (Playwright) |
